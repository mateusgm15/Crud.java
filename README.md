# CRUD de Clientes em Java

Sistema de cadastro de clientes via console, desenvolvido para praticar Programação Orientada a Objetos.

## Funcionalidades
- Cadastrar cliente
- Listar clientes
- Consultar por ID
- Alterar dados
- Excluir cliente

## Tecnologias
- Java
- ArrayList

## Como executar
1. Clone o repositório: `git clone https://github.com/mateusgm15/Crud.java.git`
2. Abra no IntelliJ
3. Execute a classe `Principal`
